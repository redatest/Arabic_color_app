# أَلْوَانِي – عَالَمٌ تَفَاعُلِيٌّ لِتَعَلُّمِ الأَلْوَانِ

تطبيق Android أصلي للأطفال الصغار لتعلّم الألوان باللغة العربية الفصحى من خلال أنشطة قصيرة وألعاب تفاعلية وصوت عربي مدمج.

## تَحْمِيلُ التَّطْبِيقِ

[تَحْمِيلُ آخِرِ إِصْدَارٍ (APK)](https://github.com/redatest/Arabic_color_app/releases/latest)

حمّل الملف **ArabicColorApp.apk** وثبّته على هاتف Android.

## المُمَيِّزَات

- واجهة عربية بالكامل من اليمين إلى اليسار.
- أرنب كرتوني يرافق الطفل في الأنشطة.
- عشرة ألوان مع بطاقات كبيرة ونطق عربي.
- خمسة ألعاب صغيرة: فرقعة البالونات، البحث عن اللون، البيضة السحرية، قطار الألوان، والاستماع ثم الاختيار.
- مؤثرات بصرية وحركات تفاعلية ورسائل تشجيع صوتية.
- نجوم ومجموعة ملصقات ومفاجآت محفوظة على الهاتف.
- يمكن إعادة تشغيل النطق والاستماع إلى أسماء الألوان بالتتابع.
- لا يحتاج تشغيل الصوت إلى تثبيت اللغة العربية على الهاتف.
- يعمل دون اتصال بالإنترنت بعد التثبيت.
- لا يجمع التطبيق أي بيانات.

## الأَصْوَاتُ

تُنشأ المقاطع الصوتية أثناء عملية البناء بصوت عربي فصيح، ثم تُضمَّن ملفات MP3 داخل APK. لا يستخدم التطبيق محرك تحويل النص إلى كلام الموجود في الهاتف، ولا يحتاج إلى اتصال بالإنترنت لتشغيل الصوت.

## الخُصُوصِيَّةُ وَالتَّشْغِيلُ

- لا WebView ولا CDN ولا أذونات إنترنت.
- التقدم والنجوم والملصقات محفوظة محليًا على الجهاز.
- لا توجد إعلانات أو مشتريات داخل التطبيق.

## البِنَاءُ وَالنَّشْرُ

كل تحديث يُدفع إلى الفرع `main` يشغّل GitHub Actions لتوليد المقاطع الصوتية العربية، ثم بناء ملف APK ونشره تلقائيًا في صفحة الإصدارات.

المصدر: Kotlin / Android SDK. الحد الأدنى Android 6.0 (API 23).
