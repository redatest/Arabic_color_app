# أَلْوَانِي – تَعَلُّمُ الأَلْوَانِ بِاللُّغَةِ العَرَبِيَّةِ

تطبيق Android أصلي للأطفال لتعلّم أسماء الألوان باللغة العربية الفصحى، من خلال بطاقات كبيرة وأشكال هندسية وأصوات عربية مسجّلة مسبقًا ومضمّنة داخل التطبيق.

## تَحْمِيلُ التَّطْبِيقِ

[تَحْمِيلُ آخِرِ إِصْدَارٍ (APK)](https://github.com/redatest/Arabic_color_app/releases/latest)

حمّل الملف **ArabicColorApp.apk** وثبّته على هاتف Android.

## المُمَيِّزَات

- عشرة ألوان بأسمائها العربية الفصحى.
- نطق صوتي عربي مضمّن داخل ملف APK.
- لا يحتاج تشغيل الصوت إلى تثبيت اللغة العربية على الهاتف.
- لا يحتاج التطبيق إلى الإنترنت بعد التثبيت.
- الضغط على بطاقة اللون لسماع اسمه.
- زر للاستماع إلى جميع الألوان بالتتابع.
- لعبة بسيطة لاختيار اللون الصحيح مع تشجيع صوتي.
- واجهة عربية من اليمين إلى اليسار.
- لا يجمع التطبيق أي بيانات.

## الأَصْوَاتُ

تُنشأ الملفات الصوتية أثناء عملية البناء بصوت عربي فصيح، ثم تُضمَّن ملفات MP3 في موارد التطبيق. لا يستخدم التطبيق محرّك تحويل النص إلى كلام الموجود في الهاتف، ولا يحتاج إلى اتصال بالإنترنت لتشغيل الصوت.

## البِنَاءُ وَالنَّشْرُ

كل تحديث يُدفع إلى الفرع `main` يشغّل GitHub Actions لتوليد المقاطع الصوتية العربية، ثم بناء ملف APK ونشره تلقائيًا في صفحة الإصدارات.

المصدر: Kotlin / Android SDK. لا WebView ولا CDN ولا أذونات إنترنت.
