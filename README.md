# ألواني – نتعلّم الألوان بالدارجة الجزائرية

تطبيق Android أصلي وبسيط لطفل عمره 3 سنوات، لتعلّم أسماء الألوان بالدارجة الجزائرية من خلال بطاقات كبيرة وأشكال واضحة وصوت.

## تحميل التطبيق

من الهاتف، افتح [آخر إصدار (APK)](https://github.com/redatest/Arabic_color_app/releases/latest) ثم حمّل الملف **ArabicColorApp.apk** وثبّته.

> عند أول تثبيت من خارج Google Play، قد يطلب Android السماح بالتثبيت من هذا المصدر.

## طريقة الاستخدام

- اضغط على بطاقة اللون لسماع اسمه بالدارجة الجزائرية.
- اضغط على زر 🔊 لسماع اللون مرة أخرى.
- زر «اسمعني» ينطق الألوان بالتتابع.
- زر «لعبة الألوان» يطلب من الطفل اختيار لون عشوائي ويشجّعه عند الإجابة الصحيحة.
- الواجهة مصممة بأزرار كبيرة وألوان وأشكال واضحة.

## الألوان المتوفرة

حمر، زرق، صفر، خضر، برتقالي، وردي، بنفسجي، كحل، بيض، بني.

## الخصوصية والتشغيل

- تطبيق Android أصلي (Kotlin)، وليس WebView.
- لا يحتاج إلى اتصال بالإنترنت.
- لا يجمع بيانات ولا يحتاج إلى صلاحيات خاصة.
- يعتمد النطق على محرّك تحويل النص إلى كلام (Text-to-Speech) المثبّت في الهاتف؛ يجب تنزيل صوت العربية من إعدادات تحويل النص إلى كلام إذا لم يكن متوفراً.

## بناء APK من المصدر

كل Push إلى الفرع `main` يشغّل GitHub Actions لبناء APK ونشره كإصدار GitHub Release.

يمكن أيضاً تشغيل البناء محلياً باستخدام Android Studio وJDK 17 وGradle 8.9.
