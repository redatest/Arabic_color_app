# أَلْوَانِي – تَعَلُّمُ الأَلْوَانِ بِاللُّغَةِ العَرَبِيَّةِ

تطبيق Android أصلي لطفل في الثالثة من العمر، لتعلّم أسماء الألوان باللغة العربية الفصحى، من خلال بطاقات كبيرة وأشكال هندسية وصوت عربي.

## تَحْمِيلُ التَّطْبِيقِ

[تَحْمِيلُ آخِرِ إِصْدَارٍ (APK)](https://github.com/redatest/Arabic_color_app/releases/latest)

حمّل الملف **ArabicColorApp.apk** وثبّته على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

## المُمَيِّزَات

- عشرة ألوان بأسمائها العربية الفصحى.
- أشكال هندسية كبيرة وواضحة.
- الضغط على بطاقة اللون لسماع اسمه.
- زر للاستماع إلى جميع الألوان بالتتابع.
- لعبة بسيطة لاختيار اللون الصحيح مع تشجيع صوتي.
- واجهة عربية من اليمين إلى اليسار.
- لا يحتاج التطبيق إلى اتصال بالإنترنت ولا يجمع أي بيانات.

## مُهِمٌّ بِخُصُوصِ الصَّوْتِ

يستخدم التطبيق محرّك تحويل النص إلى كلام (Text-to-Speech) الموجود في Android. يجب أن يكون محرّك النطق مثبتًا وأن تتوفر لديه بيانات صوت اللغة العربية.

إذا لم تسمع الصوت:
1. افتح زر **إعدادات الصوت العربي** داخل التطبيق.
2. في إعدادات تحويل النص إلى كلام، اختر محرّكًا يدعم اللغة العربية.
3. نزّل بيانات الصوت العربي، ويفضّل اختيار صوت يعمل دون إنترنت.
4. ارفع مستوى صوت الوسائط في الهاتف، وليس مستوى صوت الرنين فقط.
5. ارجع إلى التطبيق واضغط على بطاقة لون.

قد تختلف أسماء القوائم حسب نوع الهاتف وإصدار Android.

## البِنَاءُ وَالنَّشْرُ

كل تحديث يُدفع إلى الفرع \`main\` يشغّل GitHub Actions لبناء ملف APK ونشره تلقائيًا في صفحة الإصدارات.

المصدر: Kotlin / Android SDK، دون WebView أو مكتبات CDN.
